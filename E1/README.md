## Cómo ejecutar

Desde la raíz del repositorio, con Python 3.10 o superior:

```bash
python -m src.main
```

En Windows, si `python` no funciona:

```bash
py -3 -m src.main
```

**Nota:** Solo usa la biblioteca estándar de Python. No hay `requirements.txt`.
